# 缺氧基地布局规划器

不打开游戏也能设计《缺氧》（Oxygen Not Included）基地布局的单文件网页小工具。

**在线使用：https://kindkeeper.github.io/oni-base-planner/**

## 两个视图

| 页面 | 说明 |
|---|---|
| [index.html](https://kindkeeper.github.io/oni-base-planner/) （默认） | **瓷砖版**：1 格 = 1 个游戏单元格，房间按真实尺寸框选，推荐 |
| [module.html](https://kindkeeper.github.io/oni-base-planner/module.html) | 旧版模块视图：1 格 = 1 个 4×8 模块单元（粗颗粒），保留存档 |

## 瓷砖版功能

- 画布默认 120×80 格，可在左侧面板调整（偶数，32–512）
- 画笔单格连涂 / 矩形框选（实时显示 `宽×高=格数` 并对比原版房间上限，超限标红）
- 房间上限提示：宿舍/卫生 ≤64｜餐·厨·娱·医·电 ≤96（大会堂 100–120）｜公园 25–100
- 坐标原点 (0,0) = 打印舱，x 东正、y 上正，画布边缘有坐标标尺
- 左键涂色、右键擦除、滚轮缩放、空格/中键平移、双指捏合缩放
- Ctrl+Z 撤销 / Ctrl+Shift+Z 重做，改动自动保存到浏览器 localStorage
- 导出：文本（矩形清单，可贴回 AI Prompt）/ PNG 图片 / JSON 备份，支持 JSON 导入

## 操作速查

| 操作 | 效果 |
|---|---|
| 左键点击 / 拖动 | 涂色（画笔模式连涂） |
| 左键拖框 | 矩形填充（矩形模式） |
| 右键拖动 | 擦除 |
| 滚轮 | 缩放（指向光标） |
| 空格 / 中键 + 拖动 | 平移 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |

纯静态页面，无构建步骤、无依赖。本地使用直接双击打开 `index.html` 即可。
