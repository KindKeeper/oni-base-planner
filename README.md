# 缺氧基地布局涂色板

不打开游戏也能设计《缺氧》（Oxygen Not Included）基地布局的单文件网页小工具。

**在线使用：https://kindkeeper.github.io/oni-base-planner/**

## 说明

- 网格 11 列 × 15 行，每格 = 1 个房间模块单元（内空 8×4）
- 格子尺寸 60×30 px，1:2 比例，与游戏内房间 8×4 的真实长宽一致
- 竖向相邻两格合并 = 72 格双联房
- 坐标系：原点 (0,0)=打印舱单元（基地中×中4），x 右正、y 上正
- 左侧选房间类型，点/拖格子涂色；「未分配」即橡皮
- 「导出文本」生成 Markdown 坐标表 + 格数统计，复制后贴回 AI Prompt 继续讨论布局
- 纯静态单文件，无依赖；本地使用直接双击打开 `index.html`
