# 缺氧基地布局规划器

不打开游戏也能设计《缺氧》（Oxygen Not Included）基地布局的网页小工具集。

**在线使用：https://kindkeeper.github.io/oni-base-planner/**

## 页面导航

| 页面 | 说明 |
|---|---|
| [index.html](https://kindkeeper.github.io/oni-base-planner/) （默认） | **砖格版**：以房间模块为单位涂色，背景渲染真实砖格结构 |
| [tiles.html](https://kindkeeper.github.io/oni-base-planner/tiles.html) | 自由瓷砖绘制：1 格 = 1 游戏单元格，任意涂画 |
| [module.html](https://kindkeeper.github.io/oni-base-planner/module.html) | 旧版模块视图（纯色块，无砖格背景），保留存档 |

## 砖格版（index.html）结构约定

- 涂色单位 = 房间模块（11 列 × 15 行模块网格）
- 每模块横向 13 砖：**墙 1 + 内空 8 + 墙 1 + 通道井 3**（通道井 = 运载管道 / 梯子 / 金属滑杆各 1 格）
- 每模块纵向 5 砖：**内空 4 + 楼板 1**，上下相邻模块共用一层楼板
- 纵向两格合并 = 8×9 = 72 格双联房；每个模块左右墙中部各预留 2 格门位
- 坐标：模块坐标与瓷砖坐标双坐标系，原点均为打印舱（瓷砖原点 = 打印舱内空左上角）

## 功能

- 点/拖涂色模块，右键或橡皮擦除；滚轮缩放、空格/中键平移、双指捏合
- 导出文本按列纵向合并房间，直接给出**瓷砖坐标**内空矩形并校验原版房间上限（宿舍/卫生 ≤64、餐·厨·娱·医·电 ≤96、公园 25–100）
- 改动自动保存到浏览器 localStorage

## 操作速查

| 操作 | 效果 |
|---|---|
| 左键点击 / 拖动 | 涂模块 |
| 右键拖动 / 橡皮模式 | 擦除 |
| 滚轮 | 缩放（指向光标） |
| 空格 / 中键 + 拖动 | 平移 |

纯静态页面，无构建步骤、无依赖。本地使用直接双击打开对应 html 即可。
